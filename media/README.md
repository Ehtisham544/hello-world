# SIC media library
Royalty-free stock clips/photos supplied by the channel owner (Pexels / Pixabay licence: free for commercial use) used as real backgrounds.
- `clips/<tag>_<nn>_p.mp4` portrait 720x1280, `_l.mp4` landscape 1280x720, ≤ 8 s, no audio.
- `images/<tag>_*.jpg` photos (animated with slow zoom).
- `index.json` lists every item with its tag. Tags: students, study, exam, campus, city, china, graduation, documents, money.
To add new footage: transcode to both orientations like the existing files, add entries to index.json, commit.
Never add copyrighted university videos, news footage or photos of identifiable real people taken from the web.
